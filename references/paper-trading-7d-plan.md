# 7-Day Paper Trading Plan

## Goal
Build execution discipline before real capital.

## Rules
- Start paper balance: fixed (e.g., $1,000)
- Markets: BTC, ETH, SOL only
- Max 2 trades/day
- Risk per trade: 1%

## Day plan
### Day 1
- Setup chart + journal template
- Take 1 simple setup only

### Day 2-3
- Continue same setup style
- Log entry reason, stop, target, result

### Day 4
- Review mistakes (no rule changes yet)

### Day 5-6
- Repeat with stricter filtering
- Skip low-quality setups

### Day 7
- Summary:
  - Win rate
  - Avg R multiple
  - Biggest mistake pattern
  - Go/no-go for live tiny size

## Minimum graduation criteria
- Followed rules in >= 90% trades
- No revenge trades
- Drawdown contained
