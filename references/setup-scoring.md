# Setup Scoring (A/B/C)

Gunakan skor ini sebelum entry.

## A-Setup (boleh ukuran normal)
- Struktur market searah (HTF + MTF align)
- Breakout/pullback valid + volume konfirmasi
- Risk/Reward >= 1:2
- Level invalidation jelas

## B-Setup (ukuran kecil)
- Setup valid tapi ada 1-2 faktor lemah (volume tipis / HTF kurang clean)
- Risk/Reward minimal 1:1.5

## C-Setup (no trade)
- Choppy/range tanpa edge jelas
- Breakout tanpa volume
- Invalidation tidak jelas

## Rule sizing
- A: 100% dari ukuran risiko standar
- B: 50% ukuran risiko standar
- C: 0% (skip)
