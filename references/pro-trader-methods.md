# Pro Trader Methods (Compact)

## Regime-first
- Identify regime first (trend/range/high-vol event).
- Do not force trend strategies in choppy range.

## Multi-timeframe stack
- HTF (1D/4H): direction + key levels
- MTF (1H): setup confirmation
- LTF (15m): execution only

## Professional risk model
- Risk/trade: 0.5%-1.5% (max 2%)
- Daily stop: stop trading after -3R or 3 losses
- Weekly stop: reduce size after -6R week

## Setup taxonomy
1. Breakout + volume confirmation
2. Pullback continuation in trend
3. Mean-reversion only in clear range

## Execution standards
- Entry only with invalidation known.
- No averaging down without predefined ladder plan.
- No adding to losers.

## Review standards
- Track expectancy (avg win*winrate - avg loss*lossrate)
- Track rule adherence score (target >90%)
- Improve one rule at a time
