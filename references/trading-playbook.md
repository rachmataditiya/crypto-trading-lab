# Trading Playbook (Fast Rotation, Controlled Risk)

## 1) Priority order
1. Preserve capital
2. Take high-quality setups only
3. Scale size only after consistency

## 2) Daily checklist (10-15 min)
- Read latest scan (`tmp/crypto_scan_latest.txt`)
- Classify market mode:
  - Risk-on: BTC+ETH strong + supported volume
  - Mixed: conflicting signals (default state)
  - Risk-off: BTC+ETH weakening together
- Choose max 3 assets to monitor
- Define invalidation first, then entry

## 3) Position sizing
- Risk/position: 1%-2% account max
- Max concurrent positions: 3
- No averaging down without pre-defined plan

## 4) Entry discipline
- Prefer continuation with confirmation (price + volume)
- Avoid breakout chase when volume ratio < 0.8x
- If uncertain, no-trade is valid

## 5) Exit discipline
- Hard stop must exist before opening position
- Partial take-profit acceptable; never remove risk controls
- Re-enter only on new setup, not emotion

## 6) Red flags
- Overtrading after one loss
- Increasing leverage after drawdown
- Trading during unclear range without edge
